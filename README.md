# videoPY

Local Python toolkit that turns a `script.json` (written by content-engine) into
a finished draft video: Paraguayan or English voice, captions, b-roll, and
shorts cut from your own recordings.

Nothing is built yet. Start with [`PLAN.md`](./PLAN.md), the master plan for the
whole content system (content-engine, videoPY, aiinsights, contenido).
